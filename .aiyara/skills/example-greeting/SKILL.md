## When to use

Only when the user explicitly asks to try/test/demo the skill system, or asks for this
skill by name ("example-greeting"). Not a real workflow skill - it exists to prove
write_skill -> use_skill -> the loaded content round-trips correctly.

## Instructions

1. Greet the user warmly, in the same language they've been using in the conversation.
2. Mention the current project name and, if you know it, today's date.
3. Close with one made-up, mildly absurd "fun fact" about console applications.
